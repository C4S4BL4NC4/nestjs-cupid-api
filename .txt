// PLANNED STRUCTURE

// Regular user routes
POST   /auth/register
POST   /auth/login
GET    /auth/me
PATCH  /auth/me
DELETE /auth/me

// Browse profiles (all authenticated users)
GET    /profiles          → Browse profiles (public fields only)
GET    /profiles/:id      → View profile (public fields only)

// Admin routes (admin role required)
GET    /admin/profiles              → All profiles with full details
GET    /admin/profiles/:id          → Full profile details
PATCH  /admin/profiles/:id          → Edit any profile
DELETE /admin/profiles/:id          → Delete any account
PATCH  /admin/profiles/:id/suspend  → Suspend account
PATCH  /admin/profiles/:id/activate → Reactivate account
PATCH  /admin/profiles/:id/role     → Change user role



**Password hashing is handled in the user entity at auth/user.entity.ts**
